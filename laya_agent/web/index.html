laya-agent

local typed decisions, no cloud checking...

Ask Laya to pick one option, score a rubric, or answer yes/no about a short text. About 15-25 ms per call, entirely on this machine.

Ready-made primitives. Click one to load its sample input, edit it, and run.

Laya screens and routes every message (guard + intent + difficulty, one forward pass); a local Ollama model writes the reply. Requires TEXT_MODEL_BASE_URL reachable (default: local Ollama).

What this is

A local, open-weight typed-decision model (Laya, running on Apple Silicon via laya-mlx) exposed as a small classifier service: choice, score, and yes/no over short text, in one forward pass, no generated tokens, no cloud call.

It is a fast System 1 classifier and router, not a planner or a text generator. See docs/findings.md in the repo for what it is and is not good at, measured on real cases, including the failures.

Where else to use it

  • CLI: uv run laya-agent choice/score/yesno/chat/usecases
  • TUI: uv run laya-agent tui
  • HTTP API for other agents: uv run laya-agent serve
  • pi coding agent tools + bash safety gate: pi-package/
